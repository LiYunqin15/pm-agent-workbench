# 产品经理 Agent MVP PRD

版本：0.1  
状态：工程启动基线  
更新日期：2026-08-16

## 1. 产品定义

产品经理 Agent 是一套可审计的产品工作台。它将模糊任务转化为研究计划，调用获准工具收集证据，完成分析，并交付可编辑的产品材料。

它不是单纯的聊天机器人。用户必须能够看到任务状态、使用的来源、模型与预算、待审批操作和最终产物。

## 2. 目标用户

首版聚焦中小型互联网团队中的产品经理、产品负责人和创业团队成员，优先支持 Web、App、SaaS 与 AI 产品。

暂不面向医疗、金融、政务等强监管决策，也不承诺替代组织中的最终商业、法律或伦理责任人。

## 3. MVP 目标

用户可以在一个工作流中完成：

1. 输入产品背景、目标和约束。
2. 选择市场研究、竞品分析、用户洞察或 PRD 工作流。
3. 设置执行深度、自治级别与预算上限。
4. 查看 Agent 的执行阶段和采用的模型。
5. 获得有来源标记的分析结果。
6. 将结果进一步转换为 PRD、汇报提纲或结构化研究报告。

## 4. 非目标

- 首版不实现无人监督的跨系统长期自治。
- 首版不自动发布、发送、付款、删除或修改线上业务数据。
- 首版不搭建多 Agent 组织结构。
- 首版不承诺市场规模、收入预测等结论天然准确。
- 首版不绕过竞品的登录、付费、验证码或访问限制。

## 5. 核心工作流

### 5.1 市场研究

输入：市场范围、目标地区、目标用户、时间范围。  
输出：市场概览、趋势、驱动因素、约束、机会假设、证据清单和待验证问题。

### 5.2 竞品分析

输入：竞品名称或品类、体验任务、目标用户。  
输出：定位、用户路径、功能矩阵、定价、优缺点、截图索引、机会点和版本时间。

### 5.3 用户洞察

输入：访谈记录、问卷、工单、评论或研究目标。  
输出：需求聚类、行为模式、痛点、证据强度、反例、用户旅程与研究缺口。

### 5.4 PRD 草拟

输入：业务背景、问题、目标用户、约束、已有证据。  
输出：背景、目标、非目标、用户故事、流程、需求、异常场景、指标、风险和验收标准。

## 6. 自治级别

| 级别 | 含义 | MVP 行为 |
| --- | --- | --- |
| 建议 | 只分析，不执行外部操作 | 默认可用 |
| 草拟 | 研究并生成草稿 | 默认推荐 |
| 有限自治 | 在站点、预算和工具白名单内执行 | 仅低风险工具 |

任何发布、发送、购买、删除、修改线上数据、上传敏感文件或创建持久凭证的动作都必须单独审批。

## 7. 功能需求

### P0

- 任务模板与自由任务输入。
- 模型路由：快速、标准、深度。
- 预算与最大执行轮次限制。
- Web 检索接入与引用展示。
- 演示模式和真实模式必须视觉区分。
- 运行结果、模型、阶段和来源可见。
- API Key 只从服务端环境变量读取。
- 输入长度、任务类型和数值参数校验。

### P1

- 文件知识库与项目级 Vector Store。
- 可恢复的审批流程。
- DOCX、PPTX、XLSX、PDF 和 HTML 产物生成。
- 项目记忆、历史决策和术语管理。
- 任务运行轨迹与评测数据集。

### P2

- 隔离浏览器中的竞品真实体验。
- 飞书、Notion、Jira、Linear 和 Figma 连接器。
- 定期监控、变化检测和通知。

## 8. 证据标准

关键结论必须能关联到证据对象：

- URL、标题、发布方和采集时间。
- 页面摘录或截图引用。
- `事实 / 推断 / 建议`类型。
- 新鲜度、可信度和冲突信息。
- 无法访问或无法验证的明确说明。

面向用户展示 Web 检索结果时，引用必须清晰、可见且可点击。

## 9. 成功指标

| 指标 | MVP 目标 |
| --- | ---: |
| 任务成功率 | >= 80% |
| 关键事实引用覆盖率 | >= 90% |
| 无依据关键结论率 | <= 5% |
| 用户首次可用产物比例 | >= 70% |
| 文件生成成功率 | >= 98% |
| 高风险动作漏审批 | 0 |
| 标准任务 P50 完成时间 | <= 3 分钟 |

## 10. MVP 验收标准

- 无 API Key 时应用正常启动并明确显示演示模式。
- 有 API Key 时可通过 Agents SDK 完成至少一种真实任务。
- 研究类任务能够调用 Web search，并在结果区呈现引用。
- 用户可切换任务模板、执行深度、自治级别和预算。
- 无效输入获得可理解的错误提示。
- 关键路由逻辑具备自动化测试。
- 生产构建通过，不向浏览器暴露 API Key。

## 11. 后续里程碑

1. M0：工作台、单 Agent、模型路由、演示模式。
2. M1：真实 Web search、证据抽取、运行轨迹。
3. M2：文件知识库与 Office/HTML 产物。
4. M3：隔离浏览器体验和人工审批。
5. M4：项目连接器、定期任务与评测闭环。
